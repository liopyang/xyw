# 权限说明

| 功能 | 老板 | 管理员 | 代理 | 普通用户 |
|---|---:|---:|---:|---:|
| 管理端看板 | 是 | 是 | 否 | 否 |
| 全部订单 | 是 | 是 | 否 | 否 |
| 恢复订单 | 是 | 否 | 否 | 否 |
| 代理/管理员/配置维护 | 是 | 只读代理 | 否 | 否 |
| 问题处理 | 是 | 是 | 否 | 否 |
| 提交和查看自己的订单 | 否 | 否 | 是 | 否 |
| 提交和查看自己的问题 | 否 | 否 | 是 | 是 |

权限同时在路由、接口和数据查询范围三个层面执行。代理与普通用户不能通过修改请求参数访问他人数据。
